# Valuation audit outputs

This directory contains the supporting analysis and exported tables used for
the original valuation-model review and capstone deliverable. The primary
reproducible entry points are at the repository root:

- `etl.py` for Bronze/Silver/Gold preparation
- `model_pipeline.py` for the valuation benchmark
- `classifier_pipeline.py` for the Capital IQ classifier

The files here are retained as audit evidence and presentation inputs; they
are not required to score the current classifier.
